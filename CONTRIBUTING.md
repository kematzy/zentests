# Contributing

**Contributions are welcome!** Please feel free to submit a Pull Request.

The full guide lives in [docs/contributing.md](docs/contributing.md): development setup, the `make`
command reference, the branch policy and the release steps.

Use [GitHub Issues](https://github.com/kematzy/zentests/issues) for bug reports and feature
requests. When reporting a bug, include the Go version, the Fiber version and a minimal reproducing
example.
